## 3. 생성 전 배선 검사 ($0)

편당 $2 를 쓰기 전에 **돈 안 드는 검사**를 먼저 돌립니다. 아래 넷은 실제로 전부 한 번씩
틀렸던 자리입니다.

| # | 무엇 | 기대 | 결과 |
|---|---|---|---|
| 1 | DB 범위 보고가 통과하는가 | 코퍼스 범위 출력 | ✅ 908,819편, 1991-03~2026-08 |
| 2 | **인용 번호 ↔ 논문 매핑** | 제목 10개 왕복 10/10 | ✅ 10/10 |
| 3 | **검색 필터가 실제로 걸리는가** | 좁힌 결과 ⊂ 넓은 결과 | ✅ 50편 → 20편 |
| 4 | 랭킹 대체가 기록되는가 | `stats.warnings` 에 남음 | ✅ |

**2·3 은 예외 없이 조용히 틀리던 것들입니다.** 2가 깨지면 본문의 `[1]` 이 전혀 다른
논문을 가리키는 서베이가 나오고, 3이 깨지면 날짜 컷오프 게이트가 사라집니다.
둘 다 그럴듯한 PDF 가 나오기 때문에 눈으로는 못 잡습니다.

## 4. PDF 파이프라인 — 고친 버그 4건

`.md` → `.tex` → PDF 변환기에서 **참고문헌이 깨져 보이는** 문제가 있었고, 원인이 데이터가
아니라 컴파일 실패였습니다. pdflatex 이 1패스에서 죽으면 인용 번호가 전부 미해소로 남는데,
**PDF 는 만들어지고 열리기 때문에 데이터 문제처럼 보입니다.**

| # | 버그 | 증상 |
|---|---|---|
| 1 | 그리스 문자·수학 기호가 맵에 없음 | 모델이 수식을 본문 산문에 그대로 씀 (`P(y\|x) = Σ`) |
| 2 | **보호 구간이 치환을 우회** | 수식/코드 구간이 escape 를 안 거침 — em dash 151개 중 66개, θ 3개 전부가 여기 |
| 3 | **짝 없는 백틱이 산문을 삼킴** | 코드 스팬 정규식이 줄바꿈을 넘어 매치 → 문단 경계를 품은 `\texttt{}` → 컴파일 실패 |
| 4 | 스냅샷 되짚기가 조용히 폴백 | 출력 경로에 접미사가 없으면 구 DB 로 폴백 → 최신 논문 저자·제목 누락 |

**안전장치**: 남은 비ASCII 가 있으면 자동으로 xelatex 으로 컴파일합니다. 모델이 내놓는
문자를 미리 다 열거할 수 없고, **경고만 띄우던 판에서는 그 경고가 두 번 다 무시됐기**
때문입니다.

## 5. 산출물 위치

```
code/output/res/deepseek_deepseek-v4-flash-0731/                      # 구 DB
code/output/res/deepseek_deepseek-v4-flash-0731__database_2026-08/    # 신 DB
code/output/res/deepseek_deepseek-v4-flash-0731/survey-search/        # 검색 교체
code/output/res/deepseek_deepseek-v4-flash-0731/survey-search-nofresh/
eval_out/eval_*.md                                                    # 비교표
```

각 실행 디렉터리에 `.md`(본문) · `.json`(인용→arXiv id) · `.tex` · `.bib` · `.pdf` 와
중간 산출물(아웃라인 청크, 후보 풀 id, 인용 목록)이 함께 있습니다. 전부 git 추적 대상입니다.

> 설정이 다른 실행은 `exp_2` 가 아니라 **별도 디렉터리**로 갈랐습니다.
> `exp_N` 은 "같은 조건 반복"이라, 설정이 다른 실행을 exp_2 로 두면 나중에 둘을
> 평균 내는 사람이 조건 섞인 표를 만듭니다.
